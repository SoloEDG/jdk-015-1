# Resonance

安装：`npm ci`

本地启动：`npm run dev`

Docker 启动：`docker compose up --build`，访问 http://localhost:8015。

## 演出包

顶部演出栏可把当前演出保存成 `.resonance.show.zip` 演出包，并可在另一台电脑打开：

- 包内 `show.json` 记录演出名称、场景、主题参数、现场控制初始值（BPM、亮度、灵敏度、平滑、过渡、黑场/冻结/闪光）以及音频清单。
- 场景音频以内容哈希命名存放在 `audio/`，相同音频只保存一次；每个场景仍单独保存自己的音量和起点，因此共享同一素材的两个场景可以各自调整。
- 打包与打开都按分片处理并让出动画帧，大素材不会卡住正在播放的舞台；读取清单阶段不会解码音频。
- 打开前会先展示演出内容、缺失音频和不支持的内容：缺失音频可逐个替换或跳过，全部处理完才能整体确认；取消或校验失败时旧演出、音源与已录制片段保持不变。
- 确认后画面、音源、快捷场景、录制目标在同一次同步更新中切换；已经在录制的片段仍然归属于开始录制时的旧演出。
- 兼容不含现场控制设置的早期演出包（`version: 1`），缺失字段按默认值补齐并给出提示。
